# تطبيق تعلّم معنا

نسخة أولية (MVP) لتطبيق Android تعليمي للأطفال باللغة العربية.

## الأقسام الموجودة
- الحروف العربية مع أمثلة مصوّرة بالرموز التعبيرية.
- العدّ من خلال سؤال تفاعلي.
- التعرف على الألوان والأشكال.
- لعبة سؤال وجواب مع نجوم للمكافأة.
- قصة قصيرة للأطفال.

## فتح المشروع
1. ثبّت Android Studio على الكمبيوتر.
2. اختر **Open** وافتح مجلد `Taallam_Maana_Android`.
3. انتظر مزامنة Gradle وتنزيل المكتبات.
4. شغّل التطبيق على محاكي Android أو هاتف متصل USB.
5. لإنشاء APK: من قائمة Build اختر Build Bundle(s) / APK(s) ثم Build APK(s).

## ملاحظات
- هذه نسخة أولية قابلة للتطوير وليست إصداراً نهائياً للنشر.
- تحتاج النسخة التالية إلى تسجيل صوتي بشري للحروف، ورسومات أصلية، وتتبع كتابة باللمس، وحفظ تقدّم الطفل محلياً، ولوحة متابعة للولي أو المربي.
- يتطلب البناء Android Studio حديثاً وJDK 17.


## بناء APK بدون تثبيت برامج على الهاتف

1. افتح https://github.com من المتصفح وأنشئ حساباً أو سجّل الدخول.
2. أنشئ مستودعاً جديداً (New repository)، واجعله Public أو Private.
3. فك ضغط هذا الملف إن أمكن، ثم ارفع محتويات مجلد `Taallam_Maana_Android` إلى المستودع، مع الحفاظ على مجلد `.github` المخفي.
4. من صفحة المستودع افتح تبويب **Actions**.
5. اختر **Build Android APK** ثم **Run workflow** (أو انتظر انتهاء البناء التلقائي بعد رفع الملفات).
6. افتح عملية البناء الناجحة، وانزل إلى **Artifacts**، ثم حمّل `Taallam-Maana-debug-apk`.
7. افتح ملف ZIP الناتج على الهاتف واستخرج `app-debug.apk` ثم ثبّته. قد يطلب Android السماح بالتثبيت من هذا المصدر.

ملاحظة: البناء يتم على خوادم GitHub؛ لا تحتاج إلى تثبيت Android Studio أو Termux على هاتفك.
